Fantasy Premier League tooling, built as two clients over a shared data layer.

## What it is

A web application for viewing and comparing Fantasy Premier League player data, with a mobile
companion. Data comes from the game's public API. Deployed on Vercel.

## Stack

- **Web** — Next.js and React, in TypeScript.
- **Mobile** — React Native, in TypeScript, in a
  [separate repository](https://github.com/samu-el/fantasy-pl-mobile).
- **Data** — the public Fantasy Premier League API, consumed through a shared, typed data layer.
